# Base de conhecimento financeiro

Documentos educacionais usados pelo RAG do MNC Finance Chatbot.

Os textos desta pasta devem ser publicos, curtos, revisados e escritos para fins
educacionais. Eles nao devem conter recomendacoes personalizadas de investimento.

Arquivos Markdown e PDFs com texto selecionavel sao suportados. PDFs digitalizados
como imagem exigem OCR e ainda nao fazem parte desta primeira versao.

## Organizacao

- `conceitos/`: explicacoes de conceitos financeiros;
- `sources.md`: fontes gerais utilizadas como referencia.
